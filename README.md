# Movie Recommendation System Project

This project is a modified content-based movie recommendation system created for an AI/HCI course project. The system uses movie characteristics to identify and recommend similar movies.

## Original Project

This project was based on the "Movie Recommender System using Content-Based Filtering" project by Soham20030 on GitHub.

Original project:
https://github.com/Soham20030/Movie_Recommender_System_Using_Content_Based_Filtering

## Modifications

The original recommendation system was modified to:

- Display 10 movie recommendations instead of 5.
- Number the recommendations for improved readability.
- Prevent the selected movie from appearing in its own recommendation list.
- Provide a user-friendly message when an invalid movie title is entered.

## Dataset

The project uses the TMDB 5000 Movie Dataset. The `tmdb_5000_movies.csv` file is included in this repository. The larger `tmdb_5000_credits.csv` file is required to run the complete notebook but is not included in this repository due to GitHub's file upload size limitation.
